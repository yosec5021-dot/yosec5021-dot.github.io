지금 버전 (0.26.0)

만 14세 이상이라고 답한 이용자의 게임 기록은 기기와 함께 Unity 서버에도 백업되고(클라우드 저장), 랭킹과 연합에도 쓰입니다. 서버의 계정과 기록은 게임 안에서 바로 지울 수 있고(방법 1), 앱이 없으면 이메일로 요청할 수 있습니다(방법 2).

방법 1 · 게임 안에서 지우기

  1. 게임 홈 화면 오른쪽 위의 톱니(설정)를 누릅니다.
  2. 서버의 계정과 기록: 「지원」 탭 → 계정 삭제 → 삭제. 서버에 있는 게임 계정 · 클라우드 저장 기록과 백업 · 기기 변경 코드가 바로 지워지고, 연합에서 빠지며 연합 채팅에 쓴 글도 바로 지워집니다. 역대 랭킹 기록은 5일 안에 지워집니다. 이 기기의 기록은 남습니다.
  3. 이 기기의 기록: 「게임」 탭 → 데이터 초기화를 누르고 한 번 더 눌러 확인합니다. 진행 · 재화 · 장비 · 설정이 모두 지워지고 게임이 처음 상태로 돌아갑니다. 계정을 지우지 않았다면 서버의 지금 기록도 처음 상태로 바뀌고, 초기화 직전 기록은 서버 백업에 남습니다(실수로 초기화했을 때 문의로 되살릴 수 있음).

둘 다 하면 모든 기록이 사라집니다. 앱을 지우면 기기의 기록은 지워지지만 서버의 계정과 기록은 남으니, 앱을 지우기 전에 계정 삭제를 먼저 하거나 방법 2로 요청해 주세요.

yosec5021@gmail.com 으로 아래 내용을 보내 주세요. 받은 날부터 7일 안에 지우고 결과를 답장합니다.

  • 제목: 달려라 막차 계정 삭제 요청

Delete account & data

Last Train Run: Zombie Defense (달려라 막차: 좀비 디펜스) · Developer YOSEC · Package com.yosec.lasttrainrun

Current version (0.26.0)

If you say you are 14 or older, your game data is also backed up to Unity’s servers (cloud save) and used for leaderboards and guilds. You can delete the server account and data right away in the game (option 1) or by e-mail without the app (option 2).

Option 1 · In the game

  1. Tap the gear icon (Settings) at the top right of the home screen.
  2. Server account and data: “Support” tab → Delete account → Delete. Your game account, cloud save and backups, and transfer code on the server are deleted right away; you leave your guild and your guild chat lines are removed at once. All-time leaderboard records are deleted within 5 days. Data on this device stays.
  3. Data on this device: “Game” tab → Reset data, then tap again to confirm. All progress, currencies, gear and settings are deleted and the game starts over. If you did not delete the account, your current server save is reset too, and the save from just before the reset stays in the server backup (so a mistaken reset can be undone if you contact us).

Doing both removes everything. Uninstalling the app removes the data on the device but not the server account, so delete the account first or use option 2.

Option 2 · By e-mail, without the app

Send an e-mail to yosec5021@gmail.com with the subject “Last Train Run account deletion” and your in-game ID (Settings → Support → My ID → Copy; the server account ID is copied too). The server account is anonymous, so we need this ID or your transfer code to find it; without either, send your nickname and the date you last played and we will do our best. We delete the data within 7 days and reply.

What is deleted and what is kept

Deleted: game account ID, nickname, cloud save and backups, transfer code, leaderboard records, guild membership, guild chat lines and guild boss records, mail, coupon use records, crash and usage statistics (right away when you delete in the game; all-time leaderboard records, leaderboard check records, coupon use records and mail we sent to the account within 5 days).
Left anonymous: lines in last week’s leaderboard archives (no nickname — only the anonymous ID, records, icon, level and title). Unity’s leaderboard service cannot delete single lines from an archive; once your account is deleted nobody can tell whose record it was.
Kept: purchase records (order number, item, time) for 5 years as required by Korean e-commerce consumer protection law; report handling records (including the start of the reported message and the sender’s nickname) for 1 year; our operations log (time, player ID, action, reason) for 1 year; e-mail inquiries for 1 year after we reply (3 years if payment-related). Google keeps its own Google Play payment records under its policy. Deleted game data cannot be recovered.
